# 🌾 Delta Rio — Site Institucional Premium

> Site institucional de alto nível para a **Delta Rio Produtos Agrícolas LTDA**, desenvolvido com Next.js 16, Tailwind CSS v4 e Framer Motion.

---

## 🚀 Tech Stack

| Tecnologia | Versão |
|---|---|
| Next.js (App Router) | 16.2.6 |
| React | 19.2.4 |
| TypeScript | ^5 |
| Tailwind CSS | ^4 |
| Framer Motion | ^12 |
| Lenis (Smooth Scroll) | ^1.3 |
| Lucide React | ^1.16 |

---

## 🌿 Páginas

| Rota | Descrição |
|---|---|
| `/` | Home — Hero parallax, About, Serviços, Diferenciais, Galeria, Depoimentos, CTA |
| `/institucional` | Sobre a empresa — Missão, Visão, Valores, Timeline, Dados |
| `/servicos` | 8 linhas de produto em layout alternado |
| `/galeria` | Grid masonry com filtros e lightbox |
| `/insights` | Blog agrícola com filtros por tag e newsletter |
| `/contato` | Formulário + mapa + dados de contato |

---

## 🎨 Design System

- **Dark mode premium** — fundo `#060a07`
- **Verde agro** — `#22a34d`
- **Dourado** — `#c9a84c`
- **Glassmorphism** — efeito blur com bordas sutis
- **Tipografia** — Syne (display) + Space Grotesk (UI) + Inter (corpo)
- **Animações** — Framer Motion com parallax e scroll triggers

---

## 📦 Como rodar

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev

# Build de produção
npm run build
```

Acesse: [http://localhost:3000](http://localhost:3000)
